\chapter{Installation}\label{ch:a}

The attachment \texttt{code.zip} includes all \texttt{.html}, \texttt{.css}, and \texttt{.ts} source files.
It also includes all compiled \texttt{.js} files, so compilation is not required to run the software.

If you wish to run the software, see Section~\ref{sec:running}.
If you wish to recompile the \texttt{.ts} source files, see Section~\ref{sec:compilation}.

\section{Running}\label{sec:running}

\begin{itemize}
    \item Download the attachment \texttt{code.zip}.
    \item Extract it.
    \item Open the file \texttt{code/editor.html} in a browser.
\end{itemize}

\section{Compilation of TypeScript}\label{sec:compilation}

This section explains, how to compile \texttt{.ts} source files into \texttt{.js} files.

\begin{itemize}
    \item First you need to have TypeScript compiler installed.

    \begin{itemize}
        \item Install Node.js
        \item Install TypeScript compiler.
        \item Run \texttt{tsc -{}-version} to verify the installation.
    \end{itemize}

    \item Then you can compile the \texttt{.ts} source files into \texttt{.js} files.

    \begin{itemize}
        \item Open the directory \texttt{code/}.
        \item Run \texttt{tsc} to compile all \texttt{.ts} files into \texttt{.js} files.
        \item Check that a \texttt{.js} file was created for each \texttt{.ts} file.
    \end{itemize}
\end{itemize}
