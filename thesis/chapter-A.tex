\chapter{Installation}

This chapter explains how to install the software from source code.

If you do not want to install it, you can visit (TODO: link), no setup needed.

\section{Prerequisites}

Install typescript compiler.

\section{Compilation}

\begin{itemize}
    \item Open terminal.
    \item Run command \texttt{tsc -}\texttt{-version} to check if you have installed typescript compiler correctly.
    \item Open directory \texttt{code/}
    \item Run command \texttt{tsc -w} to compile all \texttt{.ts} files to \texttt{.js} files.
    \item You can check, that previous step generated \texttt{.js} file for each \texttt{.ts} file.
\end{itemize}

\section{Running}

If you have successfully compiled \texttt{.ts} files into \texttt{.js} files,
you can open the file \texttt{code/editor.html} in an internet browser.
