How to Add Jigsaw Regions
  • Left-click and drag to draw a new region..
  • Right-click a region to remove it.
  • Once you add all regions, the Sudoku will update.
Region Rules
  • All regions must have N cells.
  • All cells in a region must be connected by and edge.
  • Each cell must belong to exactly one region.
Ok
How to Add Extra Regions
  • Left-click and drag to draw a new extra region.
  • Right-click a region to remove it.
Region Rules
  • All regions must have N cells.
  • All cells in a region must be connected by an edge.
  • Two regions cannot intersect.
  • Extra regions do not need to cover every cell.
Ok
What are Sudoku Regions?
Every number has to appear exactly once in each region.
You can add regions of three main types: regular, diagonal, and extra regions.
Every row and column also counts as a region,
so each row and column must have every number exactly once as well.

Adding Variants
You can add one of five Sudoku variants.
Press button with the name of the variant you want to add.
For explanation of the variant's rules, read User documentation.
Left-click the squares between edges to toggle labels.
Right-click them to toggle the labels in the opposite direction.
If you add a transparent red X, it means that you allow all combinations of numbers in the two adjacent cells.
The transparent X will only stay visible while you are editing the variant.
